# This is the Canvas Beta copy of SALT

Canvas **Beta** loads SALT from here. Canvas **production** loads from
[DTC-Main-SALT](https://github.com/DTC-EdEx/DTC-Main-SALT).

- Don't make changes only here. Every Beta test starts by copying current
  production into this repository, then adding the change being tested.
- After a change passes in Beta, the same change goes to `DTC-Main-SALT`
  through a pull request.
- Full steps: [Testing SALT in Canvas Beta](https://github.com/DTC-EdEx/dtc-programs/blob/main/docs/canvas-beta-testing.md)

Last synced with production: DTC-Main-SALT commit `f6ce24e`.
